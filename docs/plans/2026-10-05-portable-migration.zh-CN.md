# 关注关联关系的可移植图形投影

## 基线与架构

来源：Obsidian NotEMD 1.9.12，提交 `0f493b8d3cd60553e5a517660ca1a729ce4acdfc`。DSH 已具备需要审批的修改计划、带日志的应用流程、已提交工作区事件、持久任务、产物溯源与具名导出能力。最适合迁移的缺口位于共享图形预览。

原投影把层级展平为按输入顺序排列的三列网格。父子连接缺失，中心到中心的箭头被目标节点遮盖，平行边重叠，自连接没有长度，标签被截断。七个渲染器共享这一故障机制。

## 实施内容

纯模块 `packages/notemd-artifacts/src/graph-layout.ts` 统一负责层级放置、有界关系距离优化与正交路由选择。SVG 使用方分别呈现层级连接和显式关系，连接节点边界，完整换行显示标签，并按全部几何内容计算画布边界。

兄弟节点/根节点交换只接受曼哈顿距离严格缩短的候选。没有显式关系时保留稳定的输入顺序。路由综合评估障碍、重叠、交叉和长度；自连接、平行及反向关系采用不同路径。布局保持确定性，不修改语义输入。

七个投影使用方统一采用 `graphProjectionVersion = '2'`：Mermaid、JSON Canvas、HTML、可编辑 SVG、draw.io、Drawnix、Circuitikz。未变化的语义源/原生输出指纹保持原值；可编辑 SVG 的规范源本身就是投影，因此指纹相应升级。

## 兼容性与宿主边界

- Drawnix 语义 JSON 保留全部节点与显式关系。原生适配接口、审批和任务生命周期保持不变。
- JSON Canvas 原生坐标另有实现，SVG 预览改进不代表其原生布局同步变化。
- Obsidian 的浏览器 CSS 解析与 SVG→PDF 依赖 DOM/CSSOM 及渲染器。DSH 不拥有这条路径；已有 Slidev/原生具名导出能力保持原状。
- DSH 持久任务已追加各阶段结果，并在中断/恢复时保留。再增加日志存储会造成职责冲突。
- 此处没有预览弹窗，结构化错误的显示方式由使用方决定，不向领域协议添加折叠状态。
- 检索查询的是索引内容，由已提交的工作区事件刷新。README 已纠正“每次查询重新读取仓库”的错误描述。

## 限制与回归证据

布局使用有界启发式，不保证全局最优或零交叉。路由比较最近 64 条路径，每个候选都评估节点障碍。密集图仍可能有较高开销，需要专业渲染器。文字宽度是确定性估算，不是平台字体度量。附近空间不足时，用独立注释行保留完整标签。

1,500 节点层级测试防止递归栈溢出。几何测试验证确定性、输入不变、内容覆盖、节点不重叠、关系距离缩短、节点边界连接、自连接/平行/反向关系、完整标签与画布包围。

Windows 还暴露了与图形语义无关的夹具问题：Git 中的 LF 文件检出为 CRLF，导致字节摘要失配。`.gitattributes` 现将夹具固定为 LF。未修改历史夹具内容或预期哈希。新增 `graph-projection-1912-lock.json` 记录本次干净来源，保留原有隔离证据。

安装包验收同时发现复制进包中的手册过期。现在由 prepack 步骤在打包边界同步根目录的中英文手册。
